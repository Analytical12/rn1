# RN1 — Pacote de briefing para criação do site institucional

## Objetivo

Este pacote orienta a criação de um site institucional/comercial da RN1 para empresas que precisam estruturar diagnóstico de riscos psicossociais, DRPS, relatórios, evidências e programas de saúde mental relacionados à NR-1.

## Importante

Este site **não é**:

- o app RN1 Platform;
- site da Insad;
- site do Constante;
- apenas um site pessoal da Carla.

Este site é a presença institucional/comercial da **RN1**, com Carla Gerhard como profissional responsável pela solução.

## Anexos de referência a usar

Usar como referência de conteúdo e posicionamento:

- `Apresentação NR-1_CARLA_GERHARD.pdf`
- `taste-skill-main(1).zip`
- `ui-ux-pro-max-skill-main(1).zip`
- `awesome-design-md-main(1).zip`

Regras para uso dos anexos:

1. Usar o PDF como base de conteúdo, mas revisar tom, claims e linguagem.
2. Usar os anexos de design/UI como referência de qualidade visual, composição, hierarquia, espaçamento, movimento e polimento.
3. Não copiar visual antigo literalmente.
4. Não usar azul saturado como cor principal.
5. Não usar estética genérica de apresentação/Canva.
6. Não prometer conformidade garantida, eliminação de multas ou eliminação de riscos jurídicos.

## Ordem correta de execução

1. Ler todos os arquivos deste pacote.
2. Começar pelo `01_SITE_BRIEF_RN1.md`.
3. Depois aplicar `02_SEO_E_ARQUITETURA.md`.
4. Depois usar `03_COPY_HOME_RN1.md`.
5. Depois aplicar `04_DESIGN_SYSTEM_RN1.md`.
6. Depois seguir `05_PROMPTS_POR_SECAO.md`, executando seção por seção.
7. Depois validar com `06_QA_CHECKLIST_SITE.md`.

## Entrega esperada

Ao finalizar, entregar:

- arquivos criados/alterados;
- estrutura H1/H2/H3;
- title e meta description;
- paleta aplicada;
- descrição das animações;
- screenshots ou descrição visual;
- responsividade validada;
- `tsc --noEmit` sem erros;
- `npm run build` limpo;
- pendências, se houver.
