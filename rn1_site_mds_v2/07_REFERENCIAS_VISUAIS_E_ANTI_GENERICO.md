# 07 — Referências visuais e direção anti-genérica para o site RN1

## Objetivo

Este arquivo complementa o pacote de briefing do site institucional RN1. Ele define como usar os anexos de design enviados para evitar uma landing page genérica, com cara de IA ou visual de template.

## Anexos que devem ser usados como referência

Usar estes anexos como referência de qualidade, composição e execução visual:

- `taste-skill-main(1).zip`
- `ui-ux-pro-max-skill-main(1).zip`
- `awesome-design-md-main(1).zip`
- `Apresentação NR-1_CARLA_GERHARD.pdf`

## Como usar cada anexo

### 1. `taste-skill-main(1).zip`

Usar como referência anti-slop.

Objetivo:
- evitar interface genérica;
- melhorar espaçamento;
- melhorar tipografia;
- melhorar ritmo visual;
- evitar cards todos iguais;
- evitar landing page com cara de template de IA.

Aplicar:
- mais respiro entre seções;
- hierarquia tipográfica forte;
- microcopy mais precisa;
- cards com composição intencional;
- menos blocos repetitivos;
- detalhes visuais discretos.

### 2. `ui-ux-pro-max-skill-main(1).zip`

Usar como referência para:

- refinamento de UI;
- estrutura de landing page premium;
- movimento;
- microinterações;
- responsividade;
- experiência do usuário.

Aplicar:
- animações suaves no scroll;
- transições de cards;
- hover states elegantes;
- CTA acima da dobra;
- contraste adequado;
- seções com ritmo e variação.

### 3. `awesome-design-md-main(1).zip`

Usar como referência de sistemas visuais, mas sem copiar marcas.

Referências a misturar para o cenário RN1:

#### Linear
Usar como inspiração para:
- clareza;
- sobriedade;
- hierarquia forte;
- sensação de produto técnico/confiável;
- cards bem alinhados;
- visual SaaS premium.

#### Mintlify
Usar como inspiração para:
- organização de conteúdo técnico;
- seções explicativas limpas;
- navegação clara;
- leitura escaneável;
- blocos de documentação/metodologia.

#### Cal.com
Usar como inspiração para:
- conversão;
- CTA direto;
- simplicidade;
- estrutura objetiva de SaaS.

#### Intercom
Usar como inspiração para:
- comunicação humana;
- tom acolhedor;
- visual de relacionamento com empresas;
- proximidade sem perder autoridade.

#### Clay
Usar como inspiração para:
- suavidade visual;
- estética mais humana;
- composição menos rígida;
- cards com personalidade.

#### Webflow
Usar como inspiração para:
- apresentação institucional bem acabada;
- transições e movimento;
- impacto visual sem poluição.

## Mistura recomendada para RN1

A combinação ideal para o site RN1 é:

- **Linear** para estrutura, grid, sobriedade e qualidade SaaS.
- **Mintlify** para clareza de metodologia, DRPS, NR-1 e FAQ.
- **Intercom** para tom humano, saúde mental e relacionamento com RH.
- **Clay** para suavidade visual e menos frieza corporativa.
- **Webflow** para movimento, seções mais ricas e impacto visual.
- **Cal.com** para CTAs objetivos e conversão.

## O que evitar

Não usar:

- layout “hero + 3 cards + FAQ” sem personalidade;
- cards idênticos em todas as seções;
- ícones genéricos demais;
- sombras pesadas;
- gradientes exagerados;
- azul saturado dominante;
- animação excessiva;
- copy com cara de IA;
- frases vagas como “soluções inovadoras para sua empresa”;
- promessa jurídica forte;
- seção de multa como centro da narrativa.

## Princípios visuais obrigatórios

### 1. Página com ritmo

Cada seção precisa ter composição própria:

- Hero em duas colunas.
- Problema em cards.
- Solução em timeline.
- DRPS em grid de fatores.
- Relatórios com mockup visual.
- Programas em cards compactos.
- Sobre Carla com bloco humano.
- Transparência em seção destacada.
- FAQ em accordion.
- CTA final com visual forte.

### 2. Movimento com intenção

Usar animações discretas:

- `fade-in` em seções;
- `slide-up` em cards;
- hover com elevação leve;
- transição em botões;
- card/mockup do hero com movimento sutil;
- counters ou badges com entrada suave, se fizer sentido.

Não usar:
- animações infinitas fortes;
- parallax pesado;
- textos pulando;
- autoplay agressivo.

### 3. Paleta de saúde mental corporativa

Usar:

- off-white;
- verde sálvia;
- verde profundo;
- teal;
- azul petróleo;
- cinza quente;
- grafite.

Evitar:
- vermelho;
- amarelo alerta;
- azul saturado do PDF;
- preto puro em excesso.

### 4. Copy menos genérica

Trocar frases genéricas por frases específicas.

Ruim:
“Transformamos empresas com soluções inovadoras.”

Bom:
“A RN1 estrutura diagnóstico, leitura por fatores psicossociais, relatórios e programas para apoiar RH e gestores na tomada de decisão.”

Ruim:
“Garanta conformidade com a NR-1.”

Bom:
“A RN1 apoia a organização de evidências, diagnóstico e ações preventivas relacionadas aos fatores psicossociais.”

Ruim:
“Evite multas e processos.”

Bom:
“A gestão estruturada reduz incertezas, melhora rastreabilidade e apoia decisões mais responsáveis.”

## Prompt mestre atualizado

Use este prompt antes de começar a construir ou revisar a página:

```text
Construa o site institucional RN1 com qualidade visual acima de template comum.

Use os anexos como referência:
- taste-skill-main(1).zip para anti-slop, espaçamento, tipografia e composição;
- ui-ux-pro-max-skill-main(1).zip para UX premium, movimento e responsividade;
- awesome-design-md-main(1).zip como biblioteca de referências visuais;
- Apresentação NR-1_CARLA_GERHARD.pdf como base de conteúdo comercial, mas com copy revisada.

Misture referências:
- Linear: estrutura SaaS premium, clareza e grid.
- Mintlify: explicação técnica, metodologia e FAQ.
- Intercom: tom humano, saúde mental e relacionamento.
- Clay: suavidade visual e composição menos rígida.
- Webflow: movimento e seções visualmente fortes.
- Cal.com: CTA objetivo e conversão.

Não copie nenhuma marca. Use apenas como referência de qualidade.

O site deve parecer:
- profissional;
- humano;
- confiável;
- moderno;
- específico para saúde mental corporativa;
- comercialmente forte;
- tecnicamente correto.

O site não deve parecer:
- gerado por IA;
- template genérico;
- apresentação Canva;
- app RN1 Platform;
- Insad;
- Constante;
- página alarmista de multa.

Construa por seções, validando uma a uma:
1. Header + metadata
2. Hero
3. Problema
4. Solução/timeline
5. DRPS/13 fatores
6. Relatórios/evidências
7. Programas
8. Sobre Carla
9. Transparência + FAQ
10. CTA final + footer

Cada seção deve ter:
- H2 claro;
- composição visual própria;
- bom espaçamento;
- responsividade;
- movimento suave;
- copy específica;
- sem claims jurídicos absolutos.

Ao final:
- validar H1 único;
- validar H2/H3;
- validar title/meta;
- validar mobile;
- rodar tsc;
- rodar build;
- entregar relatório.
```

## Checklist anti-genérico

Antes de considerar pronto, responder:

1. O hero comunica claramente NR-1 + riscos psicossociais?
2. O site parece uma consultoria especializada ou uma landing genérica?
3. Cada seção tem composição própria?
4. Existe movimento, mas sem exagero?
5. A paleta remete a saúde mental corporativa?
6. O texto evita promessas absolutas?
7. A Carla aparece como autoridade sem transformar o site em currículo pessoal?
8. O CTA está claro?
9. O mobile está forte?
10. A página tem cara de produto/serviço profissional real?
